# 📚 EnglishCard

Приложение для изучения английского языка на Streamlit + PostgreSQL.

## Возможности

- 🎓 10 общих слов, доступных всем пользователям
- 🎯 Викторина с 4 вариантами ответа
- ✅ Подтверждение правильного ответа
- ❌ Сообщение об ошибке с возможностью попробовать снова
- ➕ Добавление персональных слов (видны только автору)
- 🗑️ Персональное удаление слов (только своих)
- 📊 Статистика: попытки, точность, история последних ответов
- 🗄️ Просмотр схемы БД (живой из information_schema)
- 👋 Приветствие при запуске
